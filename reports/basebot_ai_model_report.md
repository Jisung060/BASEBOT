# ⚾ BASEBOT AI 모델 종합 기술 명세 및 성능 평가 보고서

본 문서는 **BASEBOT** 플랫폼에 탑재된 두 가지 핵심 인공지능 엔진인 **1) 팀 매치업 승부예측 머신러닝(ML) 모델**과 **2) 선수 시즌 성적 예측 딥러닝(DL) 모델**의 아키텍처, 입력 피처, 하이퍼파라미터 및 테스트 세트 성능 평가(Test Score) 결과를 종합 정리한 기술 명세서입니다.

## 1. AI 모델 아키텍처 한눈에 비교하기 (Summary)

| 구분 | ⚾ 팀 매치업 승부예측 모델 (ML) | 🧠 선수 시즌 성적 예측 시뮬레이터 (DL) |
| :--- | :--- | :--- |
| **적용 기술 / 프레임워크** | `Scikit-learn` (Machine Learning) | `PyTorch` (Deep Learning) |
| **핵심 알고리즘** | **Random Forest Classifier** (앙상블 결정트리 분류기) | **Multi-Output MLP** (다중 출력 다층 퍼셉트론 회귀 신경망) |
| **문제 정의 (Task)** | 이진 분류 (Binary Classification: 홈팀 승리 여부 및 승률 산출) | 다중 타깃 회귀 (Multi-Target Regression: 차기 시즌 주요 성적 동시 예측) |
| **입력 피처 (Input)** | 양 팀의 **27개 세이버메트릭스 지표 격차** ($\text{Home} - \text{Away}$) | 직전 최대 3개 시즌 가중 평균(55:30:15) 세이버 지표 + 에이징 커브 나이 (**타자 26종 / 투수 24종**) |

| **도메인 결합 (Hybrid)** | ML 모델 예측 확률(70%) + 세이버메트릭스 파워 스코어(30%) 블렌딩 | 신경망 추론값 + Statcast 기대지표(`xBA`, `xSLG`, `xERA`, `FIP`) 평균 회귀 & 출전 시나리오 보정 |
| **서비스 활용처** | 승부예측 & 팬 투표 페이지 (`prediction.html`), AI 챗봇 승부예측 | 선수 상세 페이지 플레이그라운드 (`player-detail.html`), AI 챗봇 선수 성적 전망 |

## 2. [모델 1] 팀 매치업 승부예측 머신러닝(ML) 모델

### 2.1 알고리즘 선정 및 설계 배경
* **알고리즘**: `RandomForestClassifier` (Scikit-learn 기반 배깅 앙상블 모델)
* **선정 이유**: 야구 경기 승패는 타격 생산력, 마운드 억제력, 구종 가치, 수비 범위 등 다차원 변수 간의 비선형적 상호작용으로 결정됩니다. 다수의 결정 트리를 결합하는 Random Forest는 단일 경기 노이즈에 대한 과적합(Overfitting)에 강하며, 각 세이버메트릭스 지표의 영향력(Feature Importance)을 정량적으로 해석할 수 있어 채택했습니다.

### 2.2 입력 피처 명세 (총 27개 세이버메트릭스 격차 피처: $\text{Home} - \text{Away}$)
1. **타격 & 배트 트래킹 (8종)**:
   * `diff_wrc_plus` (조정 득점 창출력 격차)
   * `diff_batting_rv` (타격 득점 가치 합계 격차)
   * `diff_xwoba` (기대 가중출루율 격차)
   * `diff_bat_speed` (평균 배트 스피드 격차)
   * `diff_squared_up_pct` (스퀘어업 정타 비율 격차)
   * `diff_exit_velo` (평균 타구속도 격차)
   * `diff_barrel_pct` (배럴 타구 비율 격차)
   * `diff_hard_hit_pct` (95mph 이상 강한 타구 비율 격차)
2. **마운드 & 구종 가치 (12종)**:
   * `diff_pitching_rv` (투구 종합 득점 가치 격차)
   * `diff_fb_rv` / `diff_brk_rv` / `diff_off_rv` (포심 패스트볼 / 변화구 / 오프스피드 구종 가치 격차)
   * `diff_era` / `diff_fip` / `diff_xera` (평균자책점 / 수비무관 자책점 / 기대 평균자책점 격차)
   * `diff_pit_xba` (투수진 피기대타율 격차)
   * `diff_fastball_velo` (포심 평균 구속 격차)
   * `diff_pit_k_pct` / `diff_pit_whiff_pct` / `diff_pit_gb_pct` (탈삼진율 / 헛스윙 유도율 / 땅볼 유도율 격차)
3. **수비 · 포수 프레이밍 · 주루 · WAR (7종)**:
   * `diff_fielding_rv` (종합 수비 득점 가치 격차)
   * `diff_team_oaa` (평균 대비 추가 아웃 카운트 처리 수 격차)
   * `diff_arm_value` (외야수 송구 득점 가치 격차)
   * `diff_framing_runs` (포수 프레이밍 득점 가치 격차)
   * `diff_bsr_rv` / `diff_sprint_speed` (주루 득점 가치 / 스프린트 스피드 격차)
   * `diff_avg_bwar` (선수단 평균 대체 선수 대비 승리 기여도 격차)

### 2.3 학습 하이퍼파라미터
* `n_estimators = 250` (결정 트리 250개 앙상블)
* `max_depth = 7` (단일 경기 우연성에 의한 과적합 방지를 위한 트리 최대 깊이 제한)
* `min_samples_split = 4`, `min_samples_leaf = 2`
* **데이터 분할**: 전체 789경기 중 학습 세트(Train) 80% (631경기) / 테스트 세트(Test) 20% (158경기), `random_state = 42`

## 3. [모델 2] 선수 시즌 성적 예측 딥러닝(DL) 모델

### 3.1 알고리즘 및 신경망 아키텍처 (`PlayerStatMLP`)
* **알고리즘**: PyTorch 기반 다중 출력 다층 퍼셉트론 (**Multi-Output MLP**)
* **설계 배경**: 선수의 여러 성적 지표(타율, 출루율, 장타율, 홈런, WAR 등)는 서로 독립적이지 않고 강한 상관관계를 가집니다. 이를 개별 단일 회귀 모델로 쪼개지 않고 하나의 신경망에서 동시에 학습(Multi-Task Learning)하여 지표 간 일관성을 확보했습니다.
* **레이어 구조**:
  $$\text{Input}(D_{\text{in}}) \rightarrow \text{Linear}(64) \rightarrow \text{LayerNorm} \rightarrow \text{GELU} \rightarrow \text{Dropout}(0.15) \rightarrow \text{Linear}(32) \rightarrow \text{LayerNorm} \rightarrow \text{GELU} \rightarrow \text{Linear}(D_{\text{out}})$$
  * **LayerNorm & GELU**: 다변량 야구 통계 지표의 스케일 차이를 안정화하고 비선형적인 에이징 커브(Aging Curve)를 부드럽게 근사합니다.
  * **Huber Loss (손실 함수)**: 부상 시즌이나 이례적인 커리어 하이 시즌 같은 이상치(Outlier)에 민감한 MSE(평균제곱오차)의 단점을 보완하여, 일정 오차 이상에서는 선형(L1)으로 동작하는 로버스트(Robust) 회귀 학습을 수행합니다.

### 3.2 시계열 전처리 및 하이퍼파라미터
* **최근성 가중 시계열 입력**: 직전 최대 3개 시즌 기록에 **55% : 30% : 15%**의 가중치를 부여해 최근 폼을 우선 반영합니다.
* **기대지표(`xStats`) 평균 회귀 결합**: 연속 시즌 전이 표본과 더불어 실제 성적이 Statcast 기대지표(`xBA`, `xSLG`, `xERA`, `FIP`) 및 나이별 에이징 커브로 수렴하는 도메인 특성을 학습에 반영했습니다.
* **하이퍼파라미터**:
  * **입출력 차원**: 타자 모델 ($26 \rightarrow 10$), 투수 모델 ($24 \rightarrow 9$)
  * **Optimizer**: `AdamW` (`lr = 0.004`, `weight_decay = 1e-4`)
  * **Loss Function**: `nn.HuberLoss()`
  * **학습 설정**: `180 Epochs`, `Batch Size = 64`, 입력/출력 Z-Score 정규화 적용

### 3.3 타자 & 투수 DL 모델 종합 평가 요약

| 구분 | 타자 성적 예측 모델 (Batter MLP) | 투수 성적 예측 모델 (Pitcher MLP) |
| :--- | :---: | :---: |
| **신경망 구조** | `Input(26) → 64 → 32 → Output(10)` | `Input(24) → 64 → 32 → Output(9)` |
| **데이터 표본 수** | **총 2,253건** (Train 1,802 / Test 451) | **총 2,164건** (Train 1,731 / Test 433) |
| **Train / Test Huber Loss** | `0.1102` / **`0.1970`** | `0.1234` / **`0.1999`** |
| **종합 평균 결정계수 ($R^2$)** | **`0.5529` (55.29% 설명력)** | **`0.5182` (51.82% 설명력)** |

## 4. 핵심 결론 및 프로젝트 차별화 포인트 (Key Takeaways)

1. **세이버메트릭스 기대지표(`xStats`)의 예측 우위 실증**:
   * ML 승부예측 모델의 피처 중요도와 DL 성적 예측 모델의 회귀 성능 모두에서 전통적인 결과 지표(`타율`, `ERA`)보다 Statcast 기반 기대 지표(`xBA`, `xwOBA`, `Bat Speed`, `xERA`, `FIP`, `Fastball Run Value`)가 미래 성적과 승패를 훨씬 더 높은 설명력으로 예측함을 데이터로 입증했습니다.
2. **실제 서비스에 즉시 적용 가능한 낮은 체감 오차 (MAE)**:
   * PyTorch Multi-Output MLP 모델은 테스트 세트에서 **타율 오차 $\pm$1푼 4리(`0.014`), 홈런 오차 $\pm$3.4개($R^2=0.635$), 투수 승수 오차 $\pm$1.26승($R^2=0.626$), 탈삼진 설명력 $R^2=0.742$**를 기록하여 실제 스카우팅 리포트 및 시뮬레이터에 즉시 활용 가능한 정확도를 확보했습니다.
3. **도메인 지식과 딥러닝의 하이브리드(Hybrid) 결합 및 인터랙티브 활용**:
   * 단순 신경망 추론에만 의존하지 않고 **선수의 만 나이 기반 에이징 커브(Aging Curve)**와 **출전 경기/이닝 시나리오(풀타임 주전·평균 유지·보수적 전망)**를 결합하여, 사용자가 웹 페이지의 **시뮬레이터 플레이그라운드**와 **AI 챗봇** 양쪽에서 자유롭게 미래 예측 및 과거 시즌 백테스트(실제 기록 비교)를 경험할 수 있도록 구현했습니다.
