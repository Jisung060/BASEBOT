BASEBOT 커뮤니티 프론트엔드

구성
html/
  community.html          게시글 목록
  community-write.html    글쓰기
  community-edit.html     글수정
  community-view.html     게시글 조회

css/
  community.css           커뮤니티 전용 CSS

js/
  community.js             분류/에디터/좋아요/스크랩/신고/댓글 UI

db/
  community_additions.sql  추가 DB 구조

주의
1. 현재 HTML은 화면과 UI 동작을 먼저 확인하기 위한 목업입니다.
2. 실제 DB 저장은 아직 연결하지 않았습니다.
3. 이미지 에디터의 현재 미리보기는 브라우저에서 확인하기 위한 것입니다.
4. 실제 서비스에서는 이미지 파일을 FastAPI로 업로드하고 community_images에 저장해야 합니다.
5. 커뮤니티 목록 화면은 목업 게시글에 league/division/team 메타데이터를 넣어 리그 → 지구 → 팀 선택에 따른 실제 프론트엔드 필터링을 확인할 수 있습니다. 예: 아메리칸리그 → 동부 → 탬파베이 레이스 선택 시 레이스 관련 게시글만 표시됩니다.
6. 기존 main.css/main.js는 팀원이 만든 파일을 그대로 사용합니다.

7. 필터는 현재 프론트엔드 목업 데이터 기준입니다. FastAPI/MySQL 연결 후 community_posts.related_team_id와 teams.league/division을 이용해 서버 조회로 교체하면 됩니다.

8. 커뮤니티 검색 영역은 MLB 실제 리그/지구 구조에 맞춘 30개 팀 데이터를 사용합니다.
   - AL: 동부/중부/서부
   - NL: 동부/중부/서부
   - 리그 → 지구 → 팀 순서로 선택하면 하위 선택지가 연동됩니다.
   - 선택 후 돋보기 아이콘이 있는 '검색' 버튼을 눌러야 게시글 필터가 적용됩니다.
   - 현재 게시글 필터는 프론트엔드 목업의 data-league/data-division/data-team 값을 기준으로 동작합니다.
   - 이후 FastAPI/MySQL 연결 시 community_posts.related_team_id와 teams.league/division을 이용해 실제 DB 조회로 교체합니다.

10. 검색 영역 상단의 "검색" 제목은 제거했습니다.
11. 팀 검색 버튼의 돋보기 아이콘을 제거하고 "검색" 텍스트만 표시합니다.
12. 샘플 게시글 8개에 AL/NL, 동부/중부/서부, 실제 MLB 팀을 명시적으로 표시하여 검색 결과를 눈으로 확인할 수 있습니다.
13. 예: AL → 동부 → 탬파베이 레이스 → 검색을 누르면 레이스 게시글 1개만 남고, 게시글 제목 위에 "AL · 동부 · 탬파베이 레이스"가 표시됩니다.

14. 사이드바 게시판 메뉴는 "전체 게시글"만 남기고, 자유/분석/경기/뉴스 분류는 검색 영역의 토글 버튼으로 이동했습니다.
15. 분류 토글 + 리그/지구/팀을 선택한 뒤 "검색" 버튼을 누르면 해당 조건으로 게시글이 필터링됩니다.
16. 게시글 목록의 최신순/조회순/추천순 정렬이 실제로 동작합니다.
   - 최신순: 날짜 → 게시글 번호 내림차순
   - 조회순: 조회수 내림차순
   - 추천순: 좋아요(추천) 수 내림차순
17. 정렬은 현재 검색 결과에 대해서 적용되며, 검색 결과 개수도 함께 표시됩니다.
