git 만드는 방법

1. 최상위 폴더 하나를 만든다
	- basebot
	
2. basebot위치까지 들어간다 -> D:\jisung\Github\basebot
	- 우클릭 시 -> Open Git Bash here -> 클릭 -> git bash가 스스로 그위치로 접속됨 -> 들어가게 되면 D:\jisung\Github\basebot(main)란 것이 뜬다 (잘되었다는 뜻)
	
3. git init (Git으로 관리되는 로컬 저장소가 됨)
	- git bash를 열었고, 내가 원하는 위치에 왔다면 git init을 입력

4. Git 사용자 정보 확인 (처음 Git을 사용하는 PC라면)
	- git config --global user.name "GitHub사용자이름"
	- git config --global user.email "GitHub이메일"
	
	- 각각 입력해준다 "" 안에는 내가 원하는 닉네임을 작성하면 된다 (이메일은 자신이 사용하는 이메일을 입력해준다)
	


--------------------------------------------------
git을 만들고 폴더를 만들었다면, 원격저장소인 GitHub에 저장해야 된다.

1. 처음 git init을 했다면, 해당 위치에 .git이 있을 것이다. 
	- .git을 클릭하는 것이 아니라 .git이 있는 위치로 가야된다 
	- 다시 Open Git Bash here로 git bash를 열어준다
	

2. git 올리는 명령어 정리 (순차적으로 작성하겠다)
	- git status -> 현재 내가 무엇을 작업했는지 대한 정보(상태)가 나온다
	- git add . -> 오늘 내가 작업한 것을 git에 올리겠다는 준비를 하는 것
	
	- git commit -m "오늘 무엇을 했는지 적는 곳" 
		-> 오늘 내가 무엇을 했는지 적는 곳이다. 그래서 하나의 기능 또는 하나의 파일을 완성했다면 수시로 올리는 것이 좋다
	
	- git push origin main -> 원격저장소와 연결한 repository에 올라가게 된다
